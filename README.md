## 功能

- 📱 设备状态显示：实时查看米家设备在线状态
- 🔌 远程开关控制：开关支持云端控制的米家设备
- 🔑 扫码登录：使用小米官方扫码授权流程（小米商城 / 米家 App）完成授权，**推荐**
- 🔐 账号密码登录：也可使用小米账号 + 密码登录（凭据仅保存于本机）
- 🔄 自动刷新：可配置刷新间隔

## 登录方式

| 方式 | 说明 | 建议 |
|------|------|------|
| 扫码登录 | 小米官方提供的扫码授权流程 | ✅ **推荐**，无需在插件中保存密码 |
| 密码登录 | 使用小米账号 + 密码登录 | 凭据仅保存在本地配置文件，不上传第三方 |

## 安装

1. 下载 `MiIsland.cipx`（Release 或自行构建）；
2. 双击 `.cipx` 文件由 ClassIsland 安装，或手动将插件文件放入 ClassIsland 的 `Plugins/MiIsland/` 目录；
3. 重启 ClassIsland，在设置中登录你的小米账号；
4. 在组件列表中找到"米家设备面板"，添加到主界面。

## 构建

```bash
dotnet publish -c Release -o publish
```

构建产物位于 `publish/`，可手动打包为 `.cipx`（zip 格式，根目录直接包含插件文件）。
