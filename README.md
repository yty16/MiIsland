在 [ClassIsland](https://classisland.tech/) 主界面显示并控制你的米家（小米智能家居）设备。

## ⚠️ 重要风险提示

- 本项目调用的是小米**未公开的私有云接口**，属于对客户端通信协议的逆向复现。
- 使用本插件**可能违反《小米用户协议》**中关于"禁止逆向、禁止非官方客户端访问"的条款。
- **请勿将本项目用于任何商业用途、规模化部署或盈利行为。**
- 小米可能随时通过风控升级封禁相关账号或变更接口，导致插件失效；由此产生的任何后果由使用者自行承担。
- 本插件**仅使用小米官方提供的「扫码登录」流程授权**，在当前设备上运行，**不收集、不存储任何账号密码**到本地文件以外的任何位置。
- 扫码登录后返回的数字账号 ID（userId）、账号昵称（米家昵称）以及登录会话令牌（serviceToken、ssecurity）会保存在本机 `settings.json` 中：
  - `userId` / 昵称**仅用于在设置页展示**当前登录的是哪个账号，不会上传或外发。
  - `serviceToken` / `ssecurity` 用于在重启 ClassIsland / 重新打开设置页时**自动恢复登录**，避免每次都重新扫码；这两项仅本地保存（经简单 XOR 混淆，**非加密**——能读取本地文件的人仍可还原）。
  - 在设置页点击"登出"会清空上述所有保存项，下次需重新扫码。

## 功能

- 📱 设备状态显示：实时查看米家设备在线状态、开关状态
- 🔌 远程开关控制：支持云端控制的插座 / 开关 / 灯
- 💡 灯亮度调节：灯类设备带亮度滑块（拖动即调，松手 0.5 秒后下发）
- 🪟 窗帘控制：开 / 停 / 关
- 🌡️ 传感器只读展示：温湿度传感器显示温度、湿度（不可控）
- 🏷️ 设备类型自动识别：按设备型号自动区分灯 / 开关 / 传感器 / 窗帘，展示对应控件
- 🔁 操作后回查：每次开关 / 调亮度 / 窗帘动作后会立即重新拉取真实状态，确认生效
- 🔑 **扫码登录（唯一登录方式）**：使用小米官方扫码授权流程（小米商城 / 米家 App），不保存任何密码
- 🔄 自动刷新：可配置刷新间隔
- 🔌 操作后实时反馈：状态栏会显示「已开启：xxx」「亮度已设为 60%」等结果
- 📍 **系统托盘图标**：安装并登录后，任务栏托盘区会出现 MiIsland 图标，**单击 / 双击即可打开独立的「米家设备控制」窗口**（无需打开 ClassIsland 主界面也能控制设备）；右键图标有「打开控制页」与「退出托盘」。关闭控制窗口只是隐藏（托盘仍可用），点「退出托盘」才会移除图标

## 登录方式

本插件**仅支持扫码登录**，使用小米官方提供的扫码授权流程完成登录：

1. 在插件设置中点击「扫码登录」；
2. 用**小米商城 / 米家 App** 扫描二维码；
3. 在手机上确认登录；
4. 插件即可读取并控制你的米家设备。

> 出于合规考虑，本插件**不提供账号密码登录**，也**不会**把你的账号密码写入任何本地文件。

## 安装

1. 在 Release 页面下载 `MiIsland.cipx`；
2. 双击 `.cipx` 文件由 ClassIsland 安装，或手动将插件文件放入 ClassIsland 的 `Plugins/MiIsland/` 目录；
3. 重启 ClassIsland，在设置中点击「扫码登录」并完成扫码；
4. 在组件列表中找到"米家设备面板"，添加到主界面。

## 把组件添加到桌面（重要，否则"看起来没用"）

插件安装并在设置页扫码登录后，**不会自动出现在桌面上**——你还需要手动把组件挂到 ClassIsland 的界面上，它才会常驻显示设备并可用：

1. 在 ClassIsland 主界面，进入**编辑模式**（通常在界面右下角或设置里开启"编辑布局"）；
2. 找到左侧/面板中的**组件（Components）**列表，搜索或找到 **「米家设备面板」**（即本插件注册的组件）；
3. 把它**拖拽或点击添加**到你想要放置的面板位置（例如"主面板"的一个格子）；
4. 退出编辑模式；
5. 此时桌面上会出现米家设备卡片：已登录则自动加载设备列表，未登录则提示去设置页登录。

> 如果你只打开了插件设置页、从没把组件加到桌面，那你看到的就只有"登录 + 设备列表"的设置界面，确实没有持续使用价值。**组件挂上桌面后，才能真正用它看状态、点开关、调亮度。**

> 组件和设置页共享同一个登录会话：在设置页扫码登录后，桌面组件会自动刷新出设备；在设置页登出，组件也会同步回到未登录状态。
