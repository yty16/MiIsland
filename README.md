- 本插件**仅使用小米官方提供的「扫码登录」流程授权**，在当前设备上运行，**不收集、不存储任何账号密码或令牌**到本地文件以外的任何位置。
- 扫码授权获得的会话保存在内存中，**重启应用后失效**，需重新扫码。

## 功能

- 📱 设备状态显示：实时查看米家设备在线状态
- 🔌 远程开关控制：开关支持云端控制的米家设备
- 🔑 **扫码登录（唯一登录方式）**：使用小米官方扫码授权流程（小米商城 / 米家 App），不保存任何密码
- 🔄 自动刷新：可配置刷新间隔

## 登录方式

本插件**仅支持扫码登录**，使用小米官方提供的扫码授权流程完成登录：

1. 在插件设置中点击「扫码登录」；
2. 用**小米商城 / 米家 App** 扫描二维码；
3. 在手机上确认登录；
4. 插件即可读取并控制你的米家设备。

> 出于合规考虑，本插件**不提供账号密码登录**，也**不会**把你的账号密码写入任何本地文件。

## 安装

1. 在 Release 页面下载 `MiIsland.cipx`；
2. 双击 `.cipx` 文件由 ClassIsland 安装，或手动将插件文件放入 ClassIsland 的 `Plugins/MiIsland/` 目录；
3. 重启 ClassIsland，在设置中点击「扫码登录」并完成扫码；
4. 在组件列表中找到"米家设备面板"，添加到主界面。
